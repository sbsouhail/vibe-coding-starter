# StudyBuddy demo kit

Everything used in the live demo, so you can repeat it yourself.

## 1. The prompt (paste into Google AI Studio › Build)

```
Build a web app called StudyBuddy for university students. They paste their course notes, and the AI creates a 10-question multiple-choice quiz with short explanations. Show the score at the end. Clean, friendly design, in French and English.
```

## 2. Sample course notes to paste into the app

Use [notes-en.md](notes-en.md) (English) or [notes-fr.md](notes-fr.md) (French).

## 3. Refinement prompts used in the demo

```
Add a 10-minute timer at the top of the quiz.
```

```
Add a "Hint" button under each question that gives a small clue without revealing the answer.
```

```
Let students choose the quiz language: French, English or Arabic.
```
