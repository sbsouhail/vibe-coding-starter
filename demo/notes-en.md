# Sample notes: Introduction to Machine Learning

Machine learning is a branch of artificial intelligence in which computers learn patterns from data instead of following rules written by a programmer. There are three main types. In supervised learning, the model is trained on labelled examples, such as emails marked "spam" or "not spam", and learns to predict the label of new data. In unsupervised learning, the data has no labels, and the model finds structure on its own, for example by grouping customers with similar buying habits; this is called clustering. In reinforcement learning, an agent learns by trial and error, receiving rewards for good actions, which is how computers learned to play games like chess and Go.

A typical project follows the same steps: collect data, clean it, split it into a training set and a test set, train the model, then evaluate it on the test set it has never seen. A common problem is overfitting, when a model memorises the training data so well that it performs badly on new data. The opposite problem, underfitting, happens when the model is too simple to capture the patterns. Accuracy is the share of correct predictions, but it can be misleading when one class is rare, so measures like precision and recall are also used.
