## Google AI Studio, step by step

1. Go to [aistudio.google.com](https://aistudio.google.com), sign in with a personal Gmail and open **Build**.
2. Paste your prompt, or remix an app from the App Gallery.
3. Watch it build: a full app with a live preview. The Gemini API key is set up for you.
4. Refine: ask for changes in the chat, or highlight a part of the screen and say what to change.
5. Something broken? Ask: "Fix any build issues with the current code."
6. Save and share: export to GitHub or download a ZIP. Share the app link only with the jury, because shared use counts against your own limits.

## Making free credits last

- **Plan before you build.** Write the idea and prompts in a free chatbot first.
- **One change per prompt.** Small, clear asks mean fewer redos.
- **Every teammate counts.** Each personal account has its own daily quota, so take turns.
- **Push to GitHub early.** When one tool runs out, continue in another.
