# Level up in Cursor (for teams who code)

Cursor is a free code editor with an AI agent inside. Its Hobby plan needs no credit card and includes a one-week Pro trial.

1. Install [Cursor](https://cursor.com), plus [Git](https://git-scm.com) and [Node.js](https://nodejs.org).
2. Clone your team's GitHub repo and open the folder.
3. Ask the agent for a change. It can edit several files at once; review each change before accepting it.
4. Run the app on your laptop. For most web apps:
   ```
   npm install
   npm run dev
   ```
5. Commit and push. Bolt and Lovable sync the change back.

Tip: keep [HANDOVER.md](HANDOVER.md) up to date so the agent understands your project.
