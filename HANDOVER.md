# Handover note (template)

Copy this file into your team repo and update it after every work session.
When you open the project in a new tool, start with: "Read HANDOVER.md first."

```
Read this file first.
App: [name], [what it does in one line].
Built with: [framework] + [AI model or API].
Done: [features that work].
Next: [the one thing to build now].
Don't change: [design, file names, anything that works].
Secrets needed: [names of API keys, never their values].
```

## Example

```
Read this file first.
App: StudyBuddy, turns course notes into a quiz.
Built with: React + Gemini API.
Done: quiz generation, score screen.
Next: add a 10-minute timer.
Don't change: design, file names.
Secrets needed: GEMINI_API_KEY.
```
